A Implantação Acontece em Quatro Fases com Valor Entregue em Cada Uma

Cada fase é independente: ao final dela, a equipe já opera com benefícios reais — sem precisar esperar a implantação completa.

1

Fase 1 · Fundação

Semanas [1–2]

Canais conectados, usuários criados, automações básicas e treinamento. A equipe já atende pela plataforma.

2

Fase 2 · Klingo

Semanas [2–3]

Integração com o sistema de agendamento: confirmações, marcações e resultados automatizados.

3

Fase 3 · CRM

Semanas [3–5]

Funis de venda e recuperação ativos. Leads organizados e cobrados automaticamente.

4

Fase 4 · IA

Semanas [5–6]

Assistente de IA agendando consultas de forma autônoma e escalando para humano quando necessário.

Cronograma condicionado à entrega dos pré-requisitos listados no slide 12. As 4 fases são sequenciais — atrasos de um lado empurram todas as fases seguintes.

O Klingo Vem em Segundo porque Elimina Trabalho Manual Imediatamente

Após a equipe já operar no Kualiz, integramos o sistema de agendamento [Klingo]. A escolha da ordem não é aleatória: a integração exige maturidade operacional — e entrega o maior ganho de tempo para a recepção.

Sem integração

Recepcionista recebe mensagem →
consulta o Klingo →
responde manualmente →
confirma →
atualiza agenda.

Cada etapa é humana.

Com integração Klingo

O paciente interage com o bot →
o sistema consulta e atualiza o Klingo automaticamente →
recepcionista só vê exceções.

Trabalho manual cai drasticamente.

A integração exige acesso técnico ao Klingo e uma janela de homologação. Os pré-requisitos estão detalhados no slide 12.

08

A Integração é Feita sob Medida — e Por Isso Exige Acesso Técnico do Cliente

Não existe um plugin de prateleira para conectar o Kualiz ao Klingo. A integração é construída especificamente para Nome do Cliente usando três mecanismos:

Requisições HTTP

A plataforma consulta e atualiza o Klingo em tempo real, buscando dados diretamente pela API do sistema.

Captura de Webhook

O Klingo avisa o Kualiz automaticamente quando algo muda na agenda — sem polling ou atualização manual.

Conexão direta ao Klingo

Em alguns fluxos, acesso direto à base de dados garante velocidade e precisão nas consultas.

kualiz klingo
GET  /agenda/horarios?data=2026-09-19
200  [ "09:00", "14:30", "16:00" ]

POST /webhooks/klingo  { "evento": "agendamento.alterado" }
200  OK

É necessário: credenciais de acesso ao Klingo, documentação da API e uma janela técnica com o time de TI do Klingo. Sem isso, a integração não avança.

13

Ser Honesto Sobre os Riscos é Parte do Nosso Método de Trabalho

Preferimos nomear os riscos aqui do que explicar uma falha no futuro. Para cada risco, temos um protocolo de mitigação.

Falha silenciosa de pagamento Meta

A API confirma o envio, mas nada é entregue. Mitigação: segundo cartão cadastrado, alerta de cobrança no financeiro e monitoramento de taxa de entrega desde o dia 1.

Aprovação de templates pode demorar ou ser recusada

A Meta avalia cada template — processo leva de 1 a 7 dias e pode reprovar sem aviso claro. Mitigação: submetemos os templates como Utilidade (não Marketing) sempre que possível e preparamos alternativas.

"Aceito pela API" não significa "entregue ao paciente"

Monitoramos entrega e leitura desde o primeiro disparo — não apenas o status de envio. Alertas automáticos quando a taxa cai.

Número novo precisa de aquecimento

Números novos na API têm limite diário baixo no início. Aumentamos gradualmente ao longo das primeiras semanas para não acionar filtros antispam da Meta.

Nossa Forma de Trabalhar Juntos Garante Previsibilidade e Agilidade

Reuniões de Acompanhamento

As reuniões são agendadas de acordo com a solicitação e disponibilidade do cliente — sem frequência fixa imposta. Sempre que necessário, a Kualiz está disponível para alinhar status, tirar dúvidas e avançar juntos.

Atendimento e Suporte

O atendimento é realizado diretamente pelo WhatsApp: (31) 99486-0390. O suporte não funciona por grupos — todas as solicitações devem ser enviadas diretamente para esse número para garantir agilidade e rastreabilidade.

Mudança de Escopo

Os prazos de atendimento são definidos de acordo com a solicitação e a complexidade de cada caso. O sistema possui diversas funcionalidades — cada demanda é avaliada individualmente antes de qualquer execução. Nada entra sem aprovação prévia.
